# Survey Data with Pandas

[![tests](https://github.com/AllenDowney/SurveyDataPandas/actions/workflows/tests.yml/badge.svg)](https://github.com/AllenDowney/SurveyDataPandas/actions/workflows/tests.yml)

Material for a tutorial at PyCon US 2025: analyzing survey data with Pandas and StatsModels, using data from the General Social Survey.

[The tutorial site](https://allendowney.github.io/SurveyDataPandas/) has the abstract, the slides, setup instructions, and links to the notebooks.

This is one of [my workshops and tutorials](https://allendowney.github.io/#workshops).
